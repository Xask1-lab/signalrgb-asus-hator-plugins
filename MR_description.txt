Title: Add ASUS TUF Gaming LC III LCD (pump screen) and HATOR Skyfall 100 Pro plugins

Hi! This MR adds two community plugins:

1. Plugins/Asus/ASUS_TUF_LC_III_LCD.js
   - Device: ASUS TUF Gaming LC III 360 ARGB LCD pump screen (USB 0B05:1C7B, interface 1)
   - Uses the SignalRGB LCD module (LCD.getFrame JPEG, 320x320) and streams frames to the pump.
   - Protocol: 1024-byte HID output report, [0x08, N, 0x00, F] + 1020 bytes of JPEG;
     first packet N = packet count, F = 0x80; following packets N = index, F = 0x00.
   - ConflictingProcesses: ASUS InfoHub.exe. Adjustable FPS (5-60).
   - Note: on my setup the image had to be rotated 180 degrees in the LCD settings.

2. Plugins/Hator/HATOR_Skyfall_100_Pro.js
   - Device: HATOR Skyfall 100 Pro keyboard (USB 379A:1806, interface 2)
   - Controls the 18 built-in hardware effects (color, speed, brightness, single/RGB colors).
   - Per-key streaming is intentionally not included: the firmware visibly flickers on every
     per-key table upload (command 0x0C), so it is not usable for live effects.
   - Protocol: 64-byte feature reports, effect packet 07 MM SS BB CM RR GG BB CHK,
     CHK = 0xFF - (sum of bytes & 0xFF).

Both protocols were reverse-engineered from USB captures (Wireshark + USBPcap) of the
official software. Tested on Windows 11 with SignalRGB 2.5.x on real hardware.

Author: Xask1. Reverse-engineering and code were done together with Claude (Anthropic AI).
